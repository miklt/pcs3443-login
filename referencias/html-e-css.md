# HTML e CSS

O frontend usa JSX/TSX para a estrutura semântica e Tailwind CSS 4 para os
estilos. Estas referências cobrem a base e a ferramenta adotada:

- [HTML — MDN](https://developer.mozilla.org/pt-BR/docs/Web/HTML);
- [CSS — MDN](https://developer.mozilla.org/pt-BR/docs/Web/CSS);
- [Formulários HTML — MDN](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Extensions/Forms);
- [Tailwind CSS](https://tailwindcss.com/docs);
- [Tailwind CSS com PostCSS](https://tailwindcss.com/docs/installation/using-postcss);
- [Design responsivo — web.dev](https://web.dev/learn/design/).

No código, `frontend/app/globals.css` importa Tailwind e os componentes usam
classes utilitárias diretamente nos elementos TSX.
